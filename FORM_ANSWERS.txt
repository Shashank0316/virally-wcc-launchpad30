WHAT PROBLEM ARE YOU SOLVING?
Founders and marketers often launch ideas and campaigns without knowing how different audience segments are likely to react before real distribution begins.

EXPLAIN THE PROBLEM IN DETAIL
Early stage teams routinely make launch decisions using intuition, a small circle of opinions, or generic engagement benchmarks. Those inputs can miss how price sensitive buyers, early adopters, skeptical users, visual audiences and community driven users react differently to the same concept. This makes iteration slower and can turn avoidable messaging mistakes into wasted creative spend, weak launches and poor reach.

WHAT IS YOUR SOLUTION?
Virally is a multi agent audience simulation platform. A user enters a business idea and marketing script or creative context. The system dispatches the same scenario to multiple synthetic audience agents, each with distinct interests, traits, habits and trust thresholds. Each agent predicts actions such as Like, Comment, Share, Save, Skip and Purchase Intent. A trend layer adjusts receptivity using market context, then an aggregation engine produces a directional Virality Index, projected reach signal, engagement, purchase intent, confidence and actionable recommendations. The user can inspect the individual agent reactions instead of trusting a single opaque score.

WHO ARE YOUR TARGET USERS?
Startup founders, product marketers, growth teams, creators, student builders and small businesses testing new ideas or marketing creatives before investing in full production or distribution.

WHAT MAKES IT DISTINCTIVE OR ORIGINAL?
Virally is built around disagreement. Instead of asking one generic AI to predict whether an idea will succeed, it creates a room of distinct audience personas with different decision rules and lets their reactions form the signal. Trend momentum changes the room over time, and every final score remains decomposable into individual persona reactions. This makes the prediction easier to interrogate, compare and improve.

TECH STACK, MODELS AND APIS USED
Frontend: HTML, CSS and JavaScript with responsive dashboard UI, SVG data visualisation, IntersectionObserver based reveals and scroll driven parallax.
Backend: Node.js HTTP server with a transparent multi agent simulation engine and JSON persistence.
Model: Persona weighted scoring model using novelty, social behavior, price sensitivity, trust, utility and visual responsiveness, with deterministic seeded variation for repeatable demo behavior.
APIs: REST endpoints for health, agents, trends, research, history and analysis.

PROMPT ARCHITECTURE AND AI WORKFLOW
The hackathon prototype uses an inspectable local simulation so judges can run the core workflow without external API keys. The agentic architecture is: normalize the idea and creative, dispatch the same scenario to specialized persona agents, evaluate each agent through persona specific traits and action rules, apply trend momentum, then aggregate the room into a decision support report. The Product Research page documents the evidence and assumptions behind the persona design and workflow.

AGENTS, CHAINS OR EVALUATION METHODS
18 persona agents, one trend adaptation layer and one aggregation layer. Evaluation is based on per persona action scores for Like, Comment, Share, Save, Skip and Purchase Intent, plus relevance, trend fit, trust, engagement, reach and confidence. The result is a directional forecast and should be validated against real audience data.
